延伸阅读

相关的优质材料不少，包括以下这些：

  • TPU Deep Dive：与本书精神相通，把 TPU 架构讲得深入又精彩。
  • Domain specific architectures for AI inference：同样是硬件与模型双线深入的佳作。
  • A Domain-Specific Supercomputer for Training Deep Neural Networks：最早一批 TPU 论文之一，讲了大量 Google TPU 计划的精彩细节，书中未曾覆盖。
  • Making Deep Learning Go Brrrr From First Principles：更偏 GPU 和 PyTorch 的 LLM 屋顶线与性能工程入门。
  • Writing TPU Kernels with Pallas：如今写 TPU 代码越来越离不开用 Pallas 写自定义内核了。这篇讲了怎么写内核，以及许多本书没提的 TPU 底层细节。
  • How to Optimize a CUDA Matmul Kernel for cuBLAS-like Performance: a Worklog：虽是 GPU/CUDA 专属，但这是一篇出色的工作记录：看一个 CUDA 矩阵乘内核如何一步步优化到位。想深入理解 TPU 与 GPU 的差别，这是好材料。
  • Distributed arrays and automatic parallelization：JAX 并行 API 的极佳指南，想动手实现本书讲的想法，从这里入手最好。
  • Rafi Witten’s High Performance LLMs 2024 Class：我们的前同事 Rafi 开的一门 TPU 性能工程好课，讲义全在 GitHub 上，许多内容比本书讲得更深。
  • [2211.05102] Efficiently Scaling Transformer Inference：讲 Transformer 推理数学的详实论文，本书的很多内容正由它启发。
  • Huggingface Ultra-Scale Playbook：某种意义上 GPU 版的“本书”，更细致地讲 PyTorch 在训练时如何实现各种并行与省内存技术。
  • Transformer Inference Arithmetic：一篇与本书想法高度一致的博文，配图画得极好。
  • Stanford CS336 Slides and Videos：斯坦福的一门出色课程，覆盖 LLM 训练与服务的诸多细节，习题很有用——作业 1 和作业 2 尤其切题。
  • Stas Bekman’s ML Engineering Handbook：一本极其实用的 ML 基础设施手册，讲的都是本书没顾上的话题：怎么和云厂商打交道、怎么管理集群、GPU 吞吐实测数字。
  • ezyang’s blog：一篇围绕分片 + PyTorch 的博客，包括一篇 PyTorch 内部机制指南和一篇分片矩阵乘笔记，此外还有许多好东西。
  • The Anatomy of Collective Communication：与本书风格相通的 GPU/TPU 集合通信详解，其中 N 维网格与 GPU 集合通信部分讲得比本书更好。

这个领域依然缺少成体系的写作，希望本书能带动更多人动笔。我们也相信这是很值得钻研和研究的领域——很多时候，手头没有多少加速卡也照样能研究。
